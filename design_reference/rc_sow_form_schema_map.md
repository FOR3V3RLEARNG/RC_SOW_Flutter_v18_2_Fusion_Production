## Form Design Rule
The app should auto-populate known house/beneficiary/parish/community/GPS/roof information from protected Shelter assessment data, while keeping permitted input editable. Structured source data should use dropdowns, toggles, numeric inputs, date controls and controlled vocabularies instead of repeated free text.
