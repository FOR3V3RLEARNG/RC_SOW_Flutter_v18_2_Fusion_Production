# RC SOW Connected Flutter

Production-oriented Flutter reconstruction of the supplied Stitch screen system for Red Cross shelter/roof-repair operations.

The application consolidates 163 supplied visual references into 58 canonical, connected product screens across 60 registered routes. Every workflow resolves to shared house, lifecycle, evidence, inventory, transfer, team, finance, notification, work-log, sync and audit state.

Release 20.0 introduces a warmer Material 3 Expressive interface: comfortable tonal surfaces, purposeful Red Cross red, asymmetric operational cards, pill-shaped status states, larger field touch targets, responsive command layouts, dark mode and reduced-motion support.

## What is connected

- Authentication entry, responsive five-destination shell and role/parish context
- Dashboard → Scope → Control → Houses → More navigation
- Scope House → Roof → Print → Files stepper
- Beneficiary lookup and house auto-fill
- Finger-first roof drafting with pan/zoom, snap, wall nodes, ridge/hip/valley,
  measurements, fall arrows, multi-structure editing, rotation and undo/redo
- Human-reviewed image-to-drawing proposals and staged legacy CSV/JSON/XLSX/PDF imports
- Duplicate-safe New Control creation
- House Command lifecycle, blockers, readiness and Smart Next Action
- Work Plan, Daily Site Log, Site Visit, Material and Consumable forms
- Document and Monitoring checklists
- Parish, cluster and house inventory ledgers with stock validation, transfers,
  consumption, leftovers and reconciliation
- Personnel and material transfers from request through approval and arrival
- Construction schedule, team resource assignments and live briefings
- Team performance, community recognition, awards, incentives and promotions
- Unified Production, Finance, Approval and HQ command workspaces
- Institutional report review and HQ sign-off
- Configurable Control divisions, tile order, visibility and density
- Completion readiness, final inspection and Payment 46/31/23 allocation
- Evidence, activity history, notifications, users online and messages
- Control-of-work logs, weekly work projections, busy-person Production Board,
  operational analytics, live tracker map, settings and accessibility
- Admin access/privileges, template versioning and Gmail compose UI
- Offline queue semantics and user-readable recovery messages

## Run

This source intentionally keeps platform scaffolding generated by the installed Flutter version. From the project root:

```bash
flutter create --platforms=android,web --project-name=rc_sow_connected --org=org.jamaicaredcross .
flutter pub get
flutter analyze
flutter test
flutter run
```

Or run `bash tool/bootstrap_and_verify.sh`.

## Automated interaction coverage

Release 20.0 includes a Green Gate for:

- Every enabled button, tile, switch, choice and navigation destination
- Real-pointer navigation journeys with fatal hit-test warnings
- Transfer, assignment, recognition, promotion, schedule, approval, finance,
  Control customization and HQ-report state transitions

Run the complete gate with `flutter analyze && flutter test`.

## Architecture

- `lib/core/models.dart` — house, lifecycle, inventory, transfer, team, evidence and collaboration contracts
- `lib/core/app_state.dart` — connected state, transitions, audit and offline queue
- `lib/core/widgets.dart` — RC SOW design-system components
- `lib/core/production_models.dart` — stock, projection, issue, import and roof geometry contracts
- `lib/core/roof_drawing_controller.dart` — manipulable drafting and history engine
- `lib/services/production_backend.dart` — local-first and Supabase adapters
- `lib/screens/` — responsive canonical screens and operational workflows
- `test/` — state, route and entry-journey contracts
- `docs/ROUTE_MATRIX.md` — canonical screen/route coverage
- `docs/STITCH_CONCEPT_COVERAGE.md` — 163-reference concept audit and consolidation map
- `docs/BACKEND_CONTRACT.md` — production integration boundary
- `supabase/migrations/` and `supabase/functions/` — protected schema and reviewed AI/import functions
- `design_reference/` — original Stitch assets retained for visual comparison

## Production service boundary

The delivered source remains fully interactive through its local-first repository. It also includes a Supabase adapter, RLS migration, OAuth callback, write RPCs, sync monitoring and protected Edge Functions for image proposals and legacy import previews. Live Gmail delivery, organization map tiles, camera capture, final PDF/XLSX generation and push notifications still require organization-owned deployment credentials and policy decisions.

No secret, service key or production credential is stored in this project.
